Draft, approve, publish

  1. Your agent drafts

    Create an MCP connection and paste its config into your agent. By default, it can only read and draft.

  2. You approve the risky part

    Publishing now, deleting and disconnecting wait in Approvals until you say yes. Each approval works once.

  3. Steerpost posts it once

    Posts go out on time. If Steerpost cannot tell whether one went out, it marks it for you to check.

Agents work within limits you set

  • Scoped keys. An agent sees only the tools its key allows.
  • Approvals. Publish now, delete and disconnect wait for your yes, unless you mark the key as trusted.
  • Revocable. Revoke a connection, and its key stops working at once.
  • Audited. Every agent action is in the audit log.

Create a connection under Developer, then paste its config:

{
  "mcpServers": {
    "steerpost": {
      "type": "http",
      "url": "http://localhost:3333/mcp",
      "headers": { "Authorization": "Bearer sk_live_..." }
    }
  }
}

Then ask: “Draft a post about our new release for LinkedIn and Telegram.”
